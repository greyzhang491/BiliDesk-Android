# 界面设计与维护

0.2.0以用户提供的参考包（元数据：`tv.danmaku.bili`，`7.14.1`）为视觉参考，采用白／灰底、粉色强调、紧凑的内容层级与轻量导航。参考来自实际解析的主题和尺寸资源；本地测试环境为x86_64、没有ARM原生桥，未运行该ARM64应用逐页比较。

## 视觉约定

| 内容 | 本项目约定 | 入口 |
| --- | --- | --- |
| 色彩与字体 | 粉色强调、深灰正文、中性灰容器；亮／暗主题分别定义，细字按实际字号排版 | `ui/Theme.kt` |
| 顶部工具栏 | 头像入口、浅灰搜索胶囊、消息与设置；个人页使用简洁标题 | `ui/AppChrome.kt` |
| 主导航 | 60dp内容高度、等宽点击区、线性未选中图标与清晰的选中状态 | `AppBottomNavigation` |
| 内容标签 | 文字＋短下划线，保留横向滚动，扩大字号时允许行高增长 | `ui/BiliApp.kt`的`Tabs` |
| 视频卡片 | 16:9封面、7dp圆角、底部局部渐变、时长标签、两行标题与UP信息 | `VideoCard` |
| 个人页 | 圆形头像、账号状态、三项常用入口、分组菜单与细分隔线 | `ui/LibraryScreen.kt` |
| 小播放条 | 圆形封面、歌曲／作者、播放和下一首、轻量进度线 | `ui/MusicPlayerScreen.kt` |

参考包中的`Brand_pink`指向`Pi5`（亮色`#FF6699`），`Bg1`／`Bg2`与`Text1`／`Text2`提供了分层思路。本项目将品牌粉用于装饰与强调，对小字采用较深的粉色和灰色，并为所有Material容器明确指定中性色，统一对话框、菜单和底栏。

图标使用项目已有的授权BiliDesk形象与AndroidX Material Icons；排版使用系统字体。测试封面由`androidTest`中的Android Canvas独立绘制并标明`UI DEMO`，仅用于验证和文档截图。参考APK仅用于本地分析。

## 交互约定

- UI负责展示与转发现有动作；播放、登录、下载和歌单存储继续使用原服务。
- 手机紧凑竖屏音乐根页沿用0.1.9的完整沉浸播放器；返回恢复上一板块和导航，平板保留双栏。
- 卡片密度、指定列数、下拉刷新、自动分页和失败重试保持可用。
- 进度条回调读取本次组合计算好的有限数值，防止曲目停止或切换后用零时长计算语义进度。
- 主题在窗口重新获得焦点时恢复系统图标颜色；沉浸播放器使用亮色系统图标，退出时还原应用主题。

修改后检查手机与平板、浅色与深色、带小播放条与完整播放器的布局；结合截图检查字号、边距、裁切和对齐，不能只以编译成功作为视觉验收。
