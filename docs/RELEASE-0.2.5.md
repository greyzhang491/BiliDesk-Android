# BiliDesk Android 0.2.5 使用说明

本版汇总0.2.3—0.2.5的跨设备同步、浮动播放、收藏管理与音乐体验更新。安装包不预置任何用户账号、应用密码、同步密钥或播放数据；云同步默认关闭，须由每位用户在设备内单独配置。

从此前的Release预览包覆盖安装可保留本机数据和已有同步配置；请先保存自己的同步恢复密钥。Actions附件使用临时调试证书，不能保证覆盖安装。

## 平时如何同步

首次配置一次后，正常使用无需进入“我的 → 跨设备同步”点击同步。

- 新建、改名、删除本机歌单，增删歌曲和修改播放队列后，自动合并并上传。
- 暂停、继续播放、切歌、拖动进度、停止、离开播放界面或切到后台时，约1秒内合并发起最新记录的上传；实际完成时间取决于网络与服务限制。
- 连续播放期间每20分钟兜底上传一次，暂停或切歌等操作会重新计算这个间隔；正常进度仍定期保存在本机，不需要每30秒上传。
- 后台补传只处理已触发但未完成的上传，不会把普通本机进度变成高频上传。断网时先保存，待联网后重试。
- 打开应用、进入音乐页和网络恢复后自动检查其他设备。前台正常轮询约20秒一次，进入后的短时间内会更快检查；网络与服务限额会影响实际时间。
- 未完成的上传会在本机加密保存，并交给系统在联网时安排后台补传。系统强行停止应用、限制后台活动、关机和断网期间，仍可能要等再次打开应用才能补传。离线时先保存修改。
- 限流、授权错误或云盘额度不足时保留本机数据，延后重试。反复切页面或切网络不会绕过服务限额。

“我的 → 跨设备同步”用于首次连接、查看同步状态与密钥、更换授权和手动重试，日常听歌不必反复进入。

## 选择要接着听的设备

1. 在音乐播放页右上方点击**设备图标**。
2. 每台其他设备各有一条记录，显示设备名、更新时间、当前歌曲、进度、歌曲数和播放模式。
3. 点选目标设备，恢复它的完整队列、当前分P与进度并开始播放。

设备按钮打开新的续播面板：封面、歌曲、播放进度、设备名称和更新时间集中展示；顶部可刷新记录。点击设备名称旁的铅笔即可修改名称，例如“随身手机”“卧室平板”；顶部“正在使用”一栏的铅笔修改本机名称。名称会加密同步到其他设备，改名不会改写播放时间、歌曲或进度。

手机昨天听的队列和平板今天听的队列会同时保留，可以自由选择。每台设备保存的是它最近一次成功传输的记录，不是该设备的全部历史快照。

“暂不恢复”只关闭这次提示，该设备仍能在设备列表中找到。选择某台设备不会删除其他设备的记录。记录到达时不会自动切歌或开始出声。

已经开始在本机播放时不显示其他设备的续播提示。接过的同一份队列和进度会记住，即使来源设备再次上传或完成最后一小段进度保存，也不会反复提示。比本机当前记录旧的内容仅保留在设备列表里，需要时可主动选取。

自动提示继续保留：进入音乐页或返回前台时，如果本机尚未播放、且发现一份更新并未处理的记录，会自动弹出续播面板。可以直接“接着听”，也能“选择其他设备”或“稍后再听”；读取记录不会自动播放。当前已在播放、正在编辑其他内容，或已接过/忽略的旧记录不会反复弹出。自动提示与手动面板使用同一套封面和排版。

多个本机歌单按标识合并，歌曲删除和歌单删除使用标记，避免离线设备重新带回旧内容。同名但不同标识的歌单仍是两个歌单。B站收藏夹由B站账号管理，与本机歌单独立。

## 唱片、歌词与原视频

播放器下方的“唱片 / 歌词 / 原视频”可以直接选择。点唱片可在唱片和歌词之间切换，歌词不可用时保持歌词页并显示状态，不再自动切到视频。

字幕会优先尝试人工中文字幕，并过滤整行的“music”“伴奏”等声音提示；这不能纠正平台字幕本身的识别错误。歌词不可用时可点击“重新读取”，也能主动选择原视频。

具有独立音轨的歌曲，切到原视频时保持原音频播放器继续工作，单独按需加载无声画面并跟随音频进度。首次画面需要网络加载；加载失败不会停掉正在听的音乐，可“重新加载画面”。返回唱片或歌词、切歌或切到后台后，释放画面播放器。仅有合并音视频的特殊内容仍需要使用视频流量，界面会提示。

## 播放队列

点击音乐播放页底部的队列图标。新版以封面、歌曲名、作者和当前歌曲高亮展示，横屏播放器左侧也使用同一套队列。

- 点击任意歌曲旁的心形按钮，选择要收藏的歌单；这首歌无需正在播放。菜单中也有“收藏到歌单”和“收藏到B站”。
- 歌曲菜单中的“下一首播放”会优先安排所选歌曲，当前歌曲继续播放。
- 顶部的定位图标可返回当前播放歌曲；首次打开队列也会定位。
- 长按歌曲左侧的拖动手柄调整顺序，靠近列表上下边缘会自动滚动；松手后保存，取消拖动会恢复原顺序。拖动预览不改正在播放的歌曲，最终顺序会随正常队列修改自动同步。
- “清空队列”位于右上角菜单，确认后停止当前播放；歌单中的歌曲保留。

## 同步流量说明

频率以操作触发为主，连续播放兜底从30秒改为20分钟。同样播放时长下，常规定时上传次数从每小时120次降到最多3次，暂停、切歌及修改歌单等操作另计。

本版仍上传压缩加密的歌单、队列与历史记录，尚未采用分文件的进度增量同步。因此不能承诺所有歌单规模、设备数量和操作频率下每月1GB都够用；坚果云账号的其他应用也会占用同一额度。以坚果云显示的实际用量及清零周期为准。

异常关机或被强行停止时，云端可能停留在上一次成功上传的位置；本机已保存的进度会保留，重新进入应用后尝试同步。

## 管理B站收藏夹

- **删除整夹**：“我的 → 我的收藏”，点击收藏夹旁的 `⋮`，选择“删除收藏夹”，确认后生效。音乐的歌单页中，B站收藏夹旁也有同样入口。
- **移除夹内视频**：打开收藏夹，点击视频封面右上角的 `⋮ → 取消收藏`，确认后移除；音乐页的收藏夹歌曲选项中也能取消收藏。
- 删除整夹会删除B站账号上该夹及其收藏记录，无法通过本机撤销；取消收藏仅移除当前夹的记录。视频原稿及其他收藏夹中的记录保留。
- 只有平台确认成功后才从列表移除。请求结果不明时先读取平台状态，也可以点击“检查结果”；应用不会自动重发删除请求。
- 平台限制、登录失效或操作被拒绝时保留原列表并显示原因。未实际删除的记录不会伪装成已删除。

## 不感兴趣

发现页长按视频封面，选择“内容不感兴趣”或“不想看这个UP主”。短视频点击右下角 `⋯ → 不感兴趣`，同样选择原因。

登录后通过B站账号提交反馈；成功后隐藏对应推荐并应用于后续发现页、短视频列表。搜索、收藏夹和主动查看UP主主页仍正常使用。后续推荐如何调整由平台决定。界面仅在提交失败或结果无法确认时提示，网络结果不明不会自动重复提交。

## 主页视频小窗缩放

打开作者或评论者主页时，原视频继续以小窗播放。拖动小窗可以移动，拖动四个边角可以放大或缩小；保持画面比例并限制在当前窗口内。单击暂停或继续，双击回到原来的普通视频或短视频界面。缩放与移动复用已有播放器，不重新加载视频。

## 第一次连接坚果云

1. 在坚果云“账户信息 → 安全选项 → 第三方应用管理”中生成独立应用密码，私下保存。
2. 在第一台设备打开“我的 → 跨设备同步 → 创建同步库”。填写坚果云账号、**第三方应用密码**及本机名称。
3. 生成并私下保存43位同步密钥，勾选说明后创建同步库。
4. 在其他设备选择“连接已有同步库”，填写相同账号、应用密码与**同一份密钥**，为每台设备起不同名称。

服务器地址由应用固定为坚果云WebDAV，无需手填地址或创建目录。实际目录是自己的 `BiliDeskSync` 下与密钥对应的子目录。第二台设备不要重新生成密钥。

同步内容为加密的歌单、队列、各设备记录和视频历史进度。缓存音视频、图片、字幕、B站Cookie及外观设置不参与同步。每台设备只写自己的文件，避免覆盖其他设备的文件。最多16台；加密单文件上限512KB，超限时停止该次上传并保留本机数据。

密钥丢失无法解密云端数据；应用密码不能代替密钥。卸载或清除数据前先保存密钥。“断开同步”只清除本机授权，保留本机歌单、队列和云端文件。更换应用密码时，保留原密钥，断开后用“连接已有同步库”重新连接。

## 排查记录未更新

先确认源设备最近联网运行过应用，并查看同步状态。目标设备打开音乐页后会自动检查；设备列表在检查时仍展示上次成功接收的记录。必要时在设置页点击“重试同步”。

授权失败时核对坚果云独立应用密码；找不到同步库或无法解密时，核对账号与同一份完整密钥。额度不足或请求频繁时等待服务限制恢复，保留本机数据继续使用。
