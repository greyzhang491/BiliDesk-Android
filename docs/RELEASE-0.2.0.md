# 0.2.0 界面更新

[音乐与歌单用法](RELEASE-0.1.8.md) · [手机音乐沉浸模式](RELEASE-0.1.9.md) · [设计与源码入口](UI-DESIGN.md) · [验证记录](VALIDATION-0.2.0.md)

这次按照参考包的视觉语言整理界面，使用粉色强调、白灰内容底、轻量图标和统一的留白。

- **发现／分区**：顶部加入胶囊搜索入口，标签采用短下划线；封面圆角更轻，播放量、时长、标题与UP信息层级更清楚。点击头像进入个人中心，消息和设置位于右上角。
- **底部导航**：收紧高度和图标间距，五项入口等宽，选中状态清楚；手机竖屏音乐页继续自动隐藏主导航，返回时恢复。
- **我的**：头像与账号状态集中展示，收藏／历史／缓存组合成常用入口，其他操作按服务与偏好分组。
- **音乐**：保留唱片、沉浸封面、简约与已有DIY设置，统一小播放条的封面、按钮和进度线；搜索、浏览其他板块时继续控制同一首歌曲。
- **浅色／深色**：统一正文、灰色容器和对话框，系统图标跟随当前主题；切换入口仍在「设置 → 主题」。

视频排列、下拉刷新、自动分页、播放手势、音质、省流和多歌单继续使用原来的设置。安装包沿用原证书，可覆盖更新。原APK仅用于本地参考，当前界面使用本项目的Compose组件、已有授权图标和系统字体。
