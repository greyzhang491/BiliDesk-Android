# 0.2.3：跨设备同步与主页小窗

本次改动随0.2.5累计公开，首次公开安装包请使用[0.2.5](RELEASE-0.2.5.md)。

- 新增默认关闭的坚果云WebDAV同步：本机歌单、音乐队列、当前歌曲与进度、视频历史使用白名单元数据加密保存。
- 每台安装写入自己的文件，歌单逐项合并并保留删除标记；恢复密钥须由用户自行保存。
- 浏览作者或评论者主页时，原视频继续以应用内小窗播放；可拖动位置，双击返回原来的普通或短视频播放。
- 授权信息与恢复密钥仅在设备内配置并通过Android Keystore保护，不作为仓库或安装包的预置配置。

当前完整操作、流量与限制见[0.2.5使用说明](RELEASE-0.2.5.md)；数据处理见[隐私说明](../PRIVACY.md)。
