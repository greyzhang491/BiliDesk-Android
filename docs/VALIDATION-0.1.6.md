# BiliDesk Android 0.1.6 音乐与更新说明

Android8.0+，版本0.1.6 / versionCode7。与0.1.5同签名，直接覆盖安装，保留登录、设置与缓存；不需要卸载旧版。

## 本轮改动

1. 音乐替代动态。B站收藏夹作为歌单，可搜新歌、立即播放、下一首播放、加入队列；支持顺序、列表循环、单曲循环、随机和上一首/下一首，队列可排序/删除/清空并保存在本机。播放歌单时显示读取进度、取消和错误；每次最多100页，达到上限会提示，后续内容仍可从分页歌单单独加入。
2. 完整音乐页采用旋转圆形唱片与封面取色背景，提供歌曲名、进度条、收藏、队列和播放控制。点唱片：有可读字幕时显示按句同步高亮/滚动歌词，可点句跳转和回到当前句；无字幕时显示原视频，再点唱片按钮切回。切换保留播放器与进度，不生成不存在的歌词。
3. 离开完整播放页浏览歌单或搜歌，底部小播放条继续播放、暂停/切歌。音乐允许后台播放，接入系统媒体控制。视频和音乐共用播放器，切换内容后只保留一路音频；音乐队列单独保留。平板宽横屏左侧歌单/队列、右侧唱片或歌词和控制；窄窗口保留小播放条。修正小播放条被系统导航栏遮挡。
4. 缓存前可选实际可用画质，以及视频（带声音）或仅音频。MP4/M4A和不同画质分开保留，音频可在音乐模式离线收听；保留分段续传、暂停/继续、重启恢复、有限重试、备用线路、合流进度和取消清理。不会改变正在观看的视频画质。
5. 短视频标题移到靠近底部，互动按钮下移；移除常驻“上下滑换片/长按下拉锁定倍数”提示。长按后下拉出现倍率选择器，继续上下移动选择1/1.25/1.5/2/2.5/3/4倍，松手锁定；选择恢复原速取消。操作期间暂时收起竖屏互动按钮。保留长按横滑调进度、左右亮度/音量、评论继续播放、点赞收藏分享；横屏始终使用常规播放控件，不叠竖屏图标与标题。
6. 推荐刷新等待追加请求后重置并返回顶部，未见内容优先；热门回退重复时有限读取后续页，无新内容时提示，不用随机打乱冒充新推荐。原有自动加载、密度与列数设置保留。
7. 保留图标、扫码登录、播放兼容、弹幕即时设置、投币诊断及自动缓存限额。自动缓存仍默认关闭；开启后默认256MB/7天、非计费Wi-Fi，保护手动与正在播放文件。图片缓存64MB，字幕小文件最多8MB；手动下载由用户管理。

## 验证与边界

- 最终APK通过78 项JVM测试；Lint0错误/31 警告。手机11 项、平板5 项场景按最终APK分次通过，本仓库保留测试方法和最终摘要，原始设备日志保存在本地交付源码包中。
- 使用独立Media3样片，实际检查音视频解码、歌词跳转、同一媒体保持、系统MediaController下一首、后台音频、收藏夹队列、倍率手势、刷新排序、缓存轨道/格式及暂停恢复。模拟画质只验证参数与轨道，样片本身不是720P。主APK不含样片或模拟接口。
- **本轮未完成真实B站网络播放、字幕接口和CDN下载验收**；上轮出口曾遇DNS/TLS和HTTP412，本轮离线交互结果不能替代平台联调。字幕/画质/内容权限以平台实际返回为准。
- 未新增红米K60/小米平板6物理设备验证，系统节电和蓝牙仍需真机确认。没有真实投币、发评、点赞、收藏或私信写入；全部互动写操作只在本地模拟。短视频复用普通视频推荐，未接官方私有Story流。
- APK签名与0.1.5相同，16KB对齐通过；源码不含私钥、账号凭据、测试媒体、构建缓存或临时网络辅助程序。
