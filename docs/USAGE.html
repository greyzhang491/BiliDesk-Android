01先用起来

适用版本：0.1.6 开发预览版　｜　Android 8.0 及以上　｜　更新日期：2026-11-04

这份说明按软件当前界面编写。先完成登录，然后按自己的习惯选择看视频、竖屏连播或听音乐。平板横屏时，主导航会放到左侧。

第一次使用，按这四步走

  1. 安装或覆盖更新 APK，打开应用。
  2. 进入「我的」，按需登录 B站账号；浏览部分公开内容可不登录。
  3. 想看视频，进入「发现」或搜索；想听歌，进入「音乐」。
  4. 进入「我的 → 设置」，检查默认清晰度、长按倍速和缓存管理。
入口主要用途
发现浏览推荐、热门、排行榜、直播和番剧；下拉刷新，接近底部自动加载。
短视频把普通视频或长视频按上下滑的方式连续观看。
分区按内容分区查找视频。
音乐收藏夹歌单、搜歌、播放队列、最近播放和离线音频。
我的登录、收藏、历史、缓存、稍后再看、追番、消息与设置。

02安装、登录与找视频

安装与更新

打开 BiliDesk-Android-0.1.6-preview.apk，按安卓系统提示完成安装。若提示来源未获安装权限，只对本次打开 APK 的应用按需授权。

从此前提供的版本更新时，直接覆盖安装，可保留登录、设置和缓存。不要为更新而先卸载或清除应用数据，这些操作会移除本机保存的数据。

两种登录方式

方式操作
扫码登录「我的」点登录，选择「扫码登录」。用另一台设备上的官方 B站 App 扫描屏幕二维码，并在官方 App 中确认。过期后点「刷新二维码」。
官方网页登录只有一部手机时，切到「官方网页登录」，在官方页面完成登录，再点「已完成登录，返回 BiliDesk」。

登录后可读取自己的收藏夹、云端历史等内容，点赞、收藏、投币等互动也需要登录。凭据加密保存在本机，不需要把账号密码交给他人。

搜索、刷新和排列

  1. 点击首页右上角搜索。可输入关键词、BV号、AV号或视频链接；也支持 b23.tv 短链接。
  2. 点击搜索按钮或键盘搜索键；点视频卡片进入播放。其他应用的“分享”菜单也可把视频链接发送到 BiliDesk。
  3. 回到列表顶部下拉，或点列表刷新按钮。刷新成功回到顶部，本次返回的新内容优先显示；失败时保留原列表。

列表靠近底部会自动加载下一页。加载失败时点重试；没有更多内容或页面重复时会停止追加。若提示「这次暂时没有新的推荐」，表示本次没有取到未见内容。

列表右上角「调整视频排列」，或「我的 → 设置 → 外观」，可选宽松、标准、紧凑，以及自动或每行1至8个。窄窗口会按可读宽度减少实际列数。

收藏、历史和消息

「我的 → 收藏」打开收藏夹；需要新建收藏夹时，先在官方 B站创建，再回本应用读取。「我的 → 历史」可切换本机记录和云端记录。稍后再看、我的追番、消息也在「我的」中；消息提供回复、@我、点赞与私信入口。

03视频播放与弹幕

打开视频后，在简介中选择分P、清晰度或播放线路，也可点赞、投币、收藏、加入稍后再看、缓存和分享。「评论」与「相关推荐」在详情标签中。

操作效果
点按画面唤出或收起常规播放控件；使用控件里的按钮暂停或继续。
拖动进度条直接跳到目标时间。
双击左侧 / 右侧快退 / 快进10秒。
按住画面临时加速，默认2倍；普通长按松手后恢复之前速度。
长按后左右滑预览目标进度，松手跳转。取消触摸不跳转；一屏最多跨约2分钟。
横屏左侧上下滑调整当前播放窗口的亮度。
横屏右侧上下滑调整媒体音量。

进入全屏与退出

点全屏按钮。手机会临时进入横屏，平板按可用窗口显示。播放中约4.5秒不操作，标题和按钮会收起；点画面可重新唤出。点退出全屏按钮或系统返回键退出。

「播放设置 → 填满视频区域」开启后会裁掉部分边缘；希望画面完整时保持关闭。原视频比例与屏幕不同，保留完整画面时出现黑边属于正常情况。

画质、倍速、弹幕与听视频

入口如何使用
播放设置调整播放倍速、长按倍速、清晰度、线路和画面填充。长按倍速可选1.25至4倍或关闭。
弹幕设置播放中调整开关、颜色、类型、透明度、显示区域、字号、速度和重复合并；滑杆即时生效。
关键词黑名单输入词语，逗号或换行分隔，再点「应用屏蔽词」。面板内有弹幕预览。
听视频 / 后台播放简介点「听视频」，或在「设置 → 播放」开启「后台播放 / 听视频」，锁屏后继续音频。

点画中画按钮可尝试小窗播放，是否允许由系统设置决定。清晰度只列出当前内容可用的流，平台账号、会员及地区权限仍然生效。

04短视频与竖屏连播

进入方式：主导航「短视频」、视频列表的「竖屏连续播放」，或普通视频简介中的「竖屏连播」。上下滑即可把普通视频、长视频连续观看。

竖屏操作效果
上滑 / 下滑切换到下一条 / 上一条。
点按画面暂停或继续播放；暂停后可使用显示出来的播放控件。
右侧互动按钮点赞、评论、收藏、系统分享。未登录的账号操作会引导登录。
底部旋转按钮在短视频模式内切换横竖屏，保留当前视频和进度。
底部「…」短视频选项：投币、稍后再看、缓存当前分P、循环或自动下一条等。

选择并锁定倍速

  1. 按住视频画面，等临时加速开始后，保持手指按住并向下拖。
  2. 出现倍率选择器后，继续上下移动，选择1、1.25、1.5、2、2.5、3或4倍；松手确认锁定。
  3. 要解除锁定，再次长按后下拉，选择「恢复原速」并松手。已经锁定时，再次下拉默认就是恢复原速。

锁定的是当前播放过程的临时速度，不会改默认倍速。切换视频、触摸取消、切到后台或离开播放页面，会清除临时状态。长按期间互动按钮暂时收起，倍率面板不会被挡住。

调进度、看评论和横屏

长按后左右滑动用于调进度，松手跳转；先向下进入倍率选择后，本次手势继续用于选择倍率。未长按的上下滑仍是换片。

打开评论时，视频会缩到剩余区域继续播放；在评论面板中滚动不会换片。关闭面板回到连播。

横屏不显示竖屏互动图标和底部标题。点画面唤出常规播放控件，不会直接暂停；左边缘约20%上下滑调亮度，右边缘约20%调音量，中间上下滑换片。评论和互动在「播放设置 → 视频互动与连播」。

默认播完循环当前视频，可在短视频选项中开启「播完自动下一条」。内容来自普通视频推荐或当前列表，与官方 App 的私有短视频推荐流不完全相同。

05音乐：从第一首歌开始

进入「音乐」，可切换「歌单」「最近」「离线」。音乐使用 B站视频内容：歌曲、演出、翻唱等都可以作为音源，新搜索的内容也能直接播放，不必先收藏。

把收藏夹当歌单

  1. 在 B站准备一个收藏夹，并把想听的歌曲视频收藏进去。已有收藏夹可直接使用。
  2. 登录后打开「音乐 → 歌单」，点收藏夹浏览歌曲，点歌曲开始播放；点歌单播放按钮或「播放全部」播放整个歌单。

读取歌单时会显示已读取数量，并可取消。每次最多读取100页，通常约2000条；达到上限会提示，其余歌曲仍可从分页歌单中单独加入队列。

搜索新歌，或把视频转为听歌

  1. 点音乐页搜索按钮，输入歌曲名、歌手或BV号并搜索。
  2. 点歌曲行立即播放；点该行「…」选择「下一首播放」「加入播放队列」「收藏到收藏夹」或「缓存音频」。

正在看普通视频时，也可在简介点「音乐播放」，转为听歌并保留当前进度。

完整播放页提供唱片切换、可拖动进度条、上一首／暂停／下一首，以及底部的播放模式、收藏和播放队列。

收藏是把内容保存到 B站收藏夹；加入播放队列只改变本机接下来听什么，不会替你收藏，也不会自动下载。

06音乐：队列、歌词与后台

决定接下来听什么

功能使用方式
立即播放直接切到所选歌曲。
下一首播放将歌曲放入优先播放列表，优先于顺序或随机模式；多首按加入顺序播放。
加入播放队列放入队列末尾，当前歌曲继续。
队列按钮查看当前歌曲；点歌曲切换。长按拖动排序手柄上下拖，或点上移按钮调整顺序。
移出 / 清空点歌曲旁的叉移出；「清空」清掉队列。移出当前歌曲会切换，清空会停止当前音乐。
播放模式自动播放行为
顺序播放按队列顺序，播完最后一首后停止。
列表循环播完队列再从头开始。
单曲循环重复当前歌曲；手动点下一首仍可切歌。
随机播放按随机顺序播放；下一首优先列表仍然有效。

唱片、歌词和原视频

唱片播放时旋转，背景随封面取色。点唱片：读到视频字幕时切到按句滚动、高亮的歌词；没有字幕时显示原视频。点「唱片」按钮切回。

歌词按原视频字幕的时间戳同步，不自动生成，也不是逐字卡拉OK。点某句可跳到该时间；手动翻看歌词后，点「回到当前」恢复跟随。字幕仍在读取时，可稍等后再查看。

仅音频缓存不含视频画面。离线时不能显示原视频；联网后才可尝试读取。切换歌词或原视频不应让歌曲从头开始。

离开播放页、锁屏与切换模式

点左上角收起按钮或系统返回键，继续搜歌、看歌单；底部小播放条可暂停、切下一首，点播放条返回完整页。音乐模式允许后台音频，系统媒体控制提供播放和切歌入口。

音乐队列和进度保存在本机，重新打开可继续。视频与音乐共用播放器：主动打开其他视频会切到视频；回音乐队列点播放可继续听。音乐本身不依赖普通视频的「听视频」开关。

07离线缓存：视频或音频

开始缓存

  1. 普通视频简介点「缓存」；短视频点「… → 缓存当前分P」。音乐页可点下载图标，或歌曲菜单「缓存音频」。
  2. 在「缓存选项」中选「视频（带声音）」或「仅音频」。视频类型再选择实际可用画质。
  3. 确认当前分P标题，点「开始缓存」。多P视频需要按自己需要选择分P后分别缓存。
  4. 到「我的 → 缓存」查看任务与已完成文件。音乐的「离线」页也会列出已完成的音频缓存。
选择得到什么
视频（带声音）保存MP4，包含画面与音频，完成后可在本地播放器观看。
仅音频保存M4A，主要用于音乐模式离线收听，不含原视频画面。
画质以内容和账号实际返回的选项为准；下载选项不改变当前正在观看的清晰度。

同一视频的音频、视频及不同画质可以分开保留，也会分别占空间。画质选项缺失时，先确认账号与视频权限，不会通过选择菜单解锁平台不提供的画质。

任务操作与进度

状态或按钮说明
暂停 / 继续保留已下载部分，之后继续。应用重启后手动任务也会保留。
重试失败后检查提示、网络与剩余空间，再重试；地址或资源变化时可能重新下载。
取消放弃任务，并清理这项任务的未完成文件。
合并中音视频下载后还要整理合并为可播放文件，完成前请保留任务。
没有明确百分比服务端未提供总大小时会显示不定进度；可看已下载字节和速度判断是否前进。

下载完成后点文件播放；音频会进入音乐播放器。删除时，在「我的 → 缓存」找到对应文件，点「删除缓存」并确认；正在播放的文件请先停止播放。

暂停或失败的手动任务会保留部分文件，也占存储。只想释放空间、不准备继续的任务，应选择取消。缓存放在应用私有目录，当前没有一键导出到公共相册的入口。

08自动缓存与空间清理

「我的 → 设置 → 缓存管理」可调整自动缓存，并查看自动缓存、手动下载和图片缓存占用。「我的 → 缓存」也能进入相关管理。

设置默认值与可选范围
自动缓存短视频默认关闭。开启后，仅在时长不超过3分钟的视频播放结束时尝试下载。
网络默认仅Wi-Fi，并要求网络未标记为按流量计费。
容量上限默认256MB；可选128、256、512、1024MB。
保留时间默认7天未播放后清理；可选1、3、7、30天。

它真的会自动清理吗？

会删除本地文件。自动缓存过期后可清理；为新缓存腾空间或超过上限时，优先清理最久没播放的自动缓存。再次播放会更新访问时间，正在播放的文件先保护，退出后再处理。空间或网络条件不合适时，会跳过或停止自动缓存。

检查发生在应用启动、自动缓存下载前后、修改容量或保留时间、停止本地播放等时机。应用完全关闭时，不会在第7天准点后台清理；下次触发检查时才处理。

内容空间与清理规则
普通在线播放使用内存缓冲；默认不会看完就保存一整段视频。
自动缓存受所设容量与过期规则管理，可点「清理自动缓存」。
手动下载的视频 / 歌曲单独保留，不由自动缓存规则删除；需要时逐项删除。旧版本已有缓存也按手动下载保留。
图片缓存独立上限64MB，可点「清理图片缓存」，之后浏览时按需重新加载。
字幕小文件读取到的字幕会有限保存，最多约8MB，方便再次查看。
256MB只约束自动缓存，不是整个软件总占用。安装文件、手动下载、下载中临时文件、图片和字幕会另外占空间。卸载或清除应用数据会移除本机保存内容，不适合作为日常清理方法。

09平板、设置与其他功能

平板横屏如何使用

允许系统旋转后横放设备。宽屏主导航在左侧；普通视频可与详情并排，全屏按钮用于只看视频。音乐宽横屏左边显示歌单或队列，右边是唱片、歌词或画面及播放控制；窄窗口保留小播放条。分屏时按实际可用宽度调整。

短视频横屏只使用常规播放控件，不叠加竖屏互动图标。需要恢复随设备旋转，可在短视频选项中选择「跟随设备旋转」。保留完整画面可能有黑边；「填满视频区域」会裁切边缘。

设置或入口用途
设置 → 外观跟随系统、深色或浅色主题；视频卡片密度与每行数量。
设置 → 播放默认清晰度、优先HEVC、线路选择、后台播放和长按倍速。
设置 → 弹幕全局弹幕设置；观看时也可从播放器即时调整。
设置 → 赞助片段跳过默认关闭。开启后向界面标示的第三方服务发送当前BV号，按社区标注跳过所选片段；下次打开视频生效。
发现 / 我的发现中可进入直播、番剧；我的中可查看追番、稍后再看和历史。内容仍受平台权限限制。

10常见问题与反馈

遇到的情况先这样处理
播放失败、黑屏或2000记录BV号和完整提示；检查网络，尝试较低清晰度或其他线路。若仍失败，可关闭「设置 → 播放 → 优先HEVC编码」，重新打开视频；对照官方App能否播放。
没有歌词先等字幕读取；视频无可读字幕或读取失败时不会生成歌词，点唱片可显示原视频。仅音频文件离线时不含画面。
锁屏后音乐停止确认当前是音乐模式；普通视频需开启「听视频」。再检查系统是否限制本应用的后台活动，具体菜单名以设备系统为准。
下载进度不动区分下载与合并阶段，查看字节和速度；检查网络、存储，必要时暂停再继续或按提示重试。没有总大小时不显示固定百分比。
刷新仍出现旧视频新内容优先排前，不代表每次平台都有全新内容；看到“没有新的推荐”可稍后再刷。失败时会保留原列表。
投币提示非法访问保留业务码和完整提示；到官方App/网页处理明确的验证要求。结果不明时先点「刷新已投枚数」，确认后再决定是否重试，不要连续点击。
清理后空间没降很多自动清理不删手动下载。检查已完成文件和暂停/失败任务；不需要的手动文件逐项删除，未完成任务取消。
全屏还有黑边 / 控件黑边与视频比例有关；播放中约4.5秒不操作会收起控件。退出全屏用返回键或退出按钮；填满画面会裁切。

反馈时带上这些信息

软件版本、设备型号和安卓版本；出问题的BV号或链接；从哪个入口操作、复现步骤；完整错误提示或截图；官方B站能否正常完成同一操作。不要提供密码、Cookie、登录令牌或有效登录二维码。

本说明对应0.1.6，之后版本的入口或行为可能调整。网页版可用浏览器“在页面中查找”搜索关键词，PDF可离线保存与打印。
