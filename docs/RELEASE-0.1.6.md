# BiliDesk Android 0.1.6 Preview

Android 8.0+，版本号0.1.6，versionCode7。开发预览版，GPL-3.0-only。

## 本次功能

- 音乐入口替代动态：收藏夹歌单、搜歌、下一首和队列、顺序/循环/单曲/随机、旋转唱片和封面取色、字幕歌词或原视频、小播放条、后台媒体控制及平板双栏。
- 缓存支持实际可用画质与视频/音频选择，保留断点续传、暂停继续、任务恢复和离线播放。
- 短视频标题与互动布局调整，移除常驻手势提示；长按下拉显示倍率选择器，继续滑动选择，松手锁定，可恢复原速。横屏不叠竖屏互动条。
- 推荐刷新重置位置，新内容优先，追加请求中触发刷新会等待后执行；平台无新内容时明确提示。
- 保留弹幕即时设置、缓存限额/过期清理、扫码登录和已有播放兼容修正。
