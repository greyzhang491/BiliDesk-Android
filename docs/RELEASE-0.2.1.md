# 0.2.1 评论区与用户主页

[安装说明](../README.md#下载与上手) · [音乐与歌单](RELEASE-0.1.8.md) · [界面设计](UI-DESIGN.md) · [验证记录](VALIDATION-0.2.1.md)

这次重新整理普通视频和短视频共用的评论区，并完善从评论进入用户主页、查看投稿的流程。

- **评论信息**：圆形头像、昵称、等级、发布日期和时间、IP属地、UP主／会员／认证标记分层显示。接口未提供的字段不编造；头像读取失败显示占位。
- **文字层级**：正文使用主题正文色；昵称加重，`@用户名`使用强调色，楼中楼放在独立灰底卡片里。保留换行、表情和带图评论；图片支持打开原图、上一张和下一张。
- **点击用户**：点头像、昵称、回复预览中的姓名或`@提及`可查看用户主页。主页展示头像、资料、可读取的粉丝／关注／投稿数、关注状态和投稿视频；点投稿开始播放。
- **提及的准确性**：接口提供UID时直接打开对应主页；只有昵称时，点击后查找用户。唯一精确匹配可直接打开，存在重名或改名时展示候选，请核对头像、昵称和UID。
- **评论互动**：点赞／取消、点踩／取消、复制评论、回复楼主或某条楼中楼。赞和踩互斥；发送回复会同时传递所属主评论和被回复的评论，避免回复错楼。
- **返回与滚动**：回复详情使用返回箭头，不再放“返回评论”文字按钮；系统返回同样生效。每个线程分别保留分页和滚动位置，从线程或用户主页回来继续看原位置。最热／最新／最早排序及自动加载保留。
- **出错与草稿**：加载失败后明确重试；发送失败保留草稿。如果网络中断导致发布结果未知，会阻止重复提交，先刷新核对，必要时清空草稿再编辑。
- **长按倍速**：长按加速时去掉画面中央的`2×／3×`悬浮框；长按加速、松手恢复、拖进度和下拉选择锁定倍率继续可用。

看评论、查看回复、浏览用户资料不会更换或暂停当前媒体。选择主页中的另一条投稿才会切换视频。长评论全文和图片可在回复详情查看；卡片预览最多显示三条回复。

资料、属地、评论和投稿是否可见仍以平台实际返回为准。昵称检索不是平台提供的UID映射；网络限制、账号隐私、改名或已删除内容会影响结果，页面提供重试及官方页面入口。发表内容仍受平台审核约束。

安装包沿用此前交付证书，可覆盖安装并保留本机数据。基础PDF和HTML仍标注0.1.6，请结合本页及音乐更新说明使用。
