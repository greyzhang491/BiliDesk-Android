# 0.2.4：设备续播、收藏与推荐管理

本次改动随0.2.5累计公开，首次公开安装包请使用[0.2.5](RELEASE-0.2.5.md)。

- 音乐页增加设备入口，各设备最近一次队列和进度分别保留；支持改名、主动选择与有条件的自动续播提示，正在播放时不反复打断。
- 歌单、队列和播放操作触发自动传输，失败保留本机状态并安排联网补传。最新频率以0.2.5的20分钟兜底策略为准。
- B站收藏夹支持删除整夹、取消夹内视频收藏；确认后提交，结果不明只读取状态，不自动重放删除请求。
- 发现页长按封面、短视频更多菜单可以提交不感兴趣及原因；确认成功后隐藏，平台后续推荐效果取决于服务端。
- 主页视频小窗支持四角缩放与边界限制，保留画面比例与原播放会话。

操作与边界见[0.2.5使用说明](RELEASE-0.2.5.md)。
