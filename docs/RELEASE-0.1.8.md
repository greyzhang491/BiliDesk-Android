## 音乐从播放器开始

点击底部「音乐」直接进入播放界面。首次使用可点「去搜歌」，或点右上角「我的歌单」选择本机歌单、B站收藏夹、最近播放与已缓存音频。平板横屏可同时显示左侧歌单和右侧播放器。

播放页保留上一首、暂停／播放、下一首、进度、播放模式、收藏与队列。离开去搜索、浏览歌单时，底部小播放条继续控制同一个播放器；锁屏与系统媒体控制也使用当前队列。

## 多个歌单与合集选曲

「我的歌单」分为**本机歌单**和**B站收藏夹**：

- 本机歌单无需登录，可创建多个、重命名、删除、增删歌曲，精确保存视频的分P。它保存在当前设备，退出B站账号不会删除，也不会自动同步到云端。清除应用数据或卸载前请注意保留需要的内容。
- B站收藏夹读取当前账号的收藏。可以在这里新建收藏夹，也能在视频、短视频和音乐的收藏面板内新建；默认为私密，可在创建时选择公开。平台收藏通常对应整个视频，而非某个分P。
- 正在播放的队列独立保存。浏览或编辑另一歌单、删除歌单、把歌曲保存到歌单，都不会替换正在播放的队列。点击「播放全部」或歌单播放按钮才会开始播放所选歌单。

歌曲行的「⋮」和播放页右上角的「⋮」提供「加入歌单」「合集 / 分P选曲」。选曲页会合并当前视频的分P与平台返回的UGC合集，按视频与cid去重；可以全选、反选，或逐首勾选后加入指定歌单，也可以只加入队列。保存到已有歌单会保留原顺序并跳过相同歌曲。单个本机歌单最多5000首、最多200个歌单；平台未返回完整合集时会提示，不能把未返回的内容算作已导入。

## 省流与原视频

默认选择「省流」音质，优先使用平台实际提供的最低码率AAC音轨。纯听歌时播放器只建立独立音频源，跳过视频源与视频线路测速。均衡、高音质按可用音轨选择，并受账号与内容权限限制。

播放器设置会按音轨声明的码率估算流量，例如64kbps约28.8MB/小时；这不是套餐用量保证，封面、字幕和接口请求另计。同一视频只提供一个音轨时，切换音质不能凭空得到更低码率。

点唱片可切换到滚动字幕歌词；没有字幕时，显示原视频画面。**原视频会使用视频流量**，从歌曲选项也能主动切换。返回唱片或歌词、离开播放页或退到系统桌面后恢复纯音频源。切换复用同一个播放器、曲目和进度，但切源时仍可能短暂缓冲。没有独立音轨的内容会明确提示，可主动使用原视频播放，不能承诺此时节省视频流量。

本地音频缓存无需重复下载媒体流；本地视频作为音乐收听时也不需要下载视频。字幕来自可读取的视频字幕，不生成或抓取其他来源歌词。歌词去掉句首／句尾的音符装饰，保留文字、原始时间戳与内部符号。

## 播放器外观DIY

右上角调色板打开「音乐播放器设置」：

| 设置 | 效果 |
| --- | --- |
| 经典唱片 / 沉浸封面 / 简约 | 切换唱片或封面展示方式 |
| 封面自动取色 | 背景与强调色随封面变化 |
| 预设颜色 / `#RRGGBB` | 使用指定配色，同时关闭自动取色 |
| 背景深度、封面大小 | 调整明暗与封面比例 |
| 歌词字号、左对齐 | 调整歌词阅读方式 |
| 唱片旋转 | 开关动效，暂停时停止旋转 |
| 省流 / 均衡 / 高音质 | 切换当前与后续音乐的音轨选择策略 |

设置保存在本机，下次打开继续使用；「恢复默认设置」可重置。音乐样式不改变普通视频的横屏控制和手势。

底部播放模式、收藏、队列三组采用等宽布局，统一图形尺寸与点击区，各自居中、图标同一基线；收藏星星固定在播放器水平中间，不受播放模式名称长短影响。

## 关注、评论与收藏

视频简介中的关注按钮读取账号关系，已关注会显示「已关注」。点击可取消，再次点击可关注；提交期间禁止连点，失败时可重新读取状态，不把读取失败当作未关注。

普通视频与短视频使用相同评论组件。点击赞数可点赞／取消，点击「查看N条回复」进入楼中楼。排序菜单支持最热、最新、最早；最早会定位服务端最后一页后反向读取，不把已载入的一页倒序冒充所有评论的最早顺序。平台没有提供总页数时会提示改用其他排序。打开评论和回复不暂停、不替换当前播放媒体。

收藏时点「新建收藏夹」填写名称、选择可见性，创建成功后选择新收藏夹即可收藏。网络中断导致创建结果不明时，请关闭面板并刷新确认，避免重复创建。所有平台写操作仅由用户主动点击发起；账号权限、验证要求和服务端错误仍会保留。

## 锁定倍速后的暂停

长按下拉仍可选择并锁定倍速。锁定标记仅在播放且控件可见时显示在角落，暂停时不显示，不再用中央悬浮层阻挡恢复播放。再次长按下拉可选择恢复原速。
