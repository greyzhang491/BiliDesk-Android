# BiliDesk Android 0.1.7 Preview

Android 8.0+，版本0.1.7，versionCode8。此版本修复断网重连后误判未登录的问题。

## 修复内容

- 启动时从本机恢复已保存的会话和上次验证的账号资料。断网、超时、服务器异常或无法解析的账号返回，不再直接显示为未登录。
- 回到前台、默认网络恢复或 Wi-Fi/移动网络切换后自动尝试账号校验；并发校验合并，已验证状态的频繁前台事件会限流，不持续后台轮询。
- “我的”页面显示账号同步状态，并提供“重试同步”。旧版本已有 Cookie、但还没保存账号资料时，离线显示“已保存的账号”，联网后补全资料，无需因此重新扫码。
- 上次验证的账号资料与当前会话绑定，并使用 Android Keystore AES-GCM 加密。暂时无法读取本机会话时保留原加密数据，允许之后重试，避免自动清空凭据。
- 关键会话与资料在 I/O 线程确认写入后才报告完成，避免进程在异步写入落盘前结束而丢失会话；退出同样等待清除结果。
- 平台明确返回账号未登录或会话过期时，仍要求重新登录。退出登录会清除会话及绑定资料，并阻止迟到的校验结果或账号 Cookie 恢复旧登录。

账号恢复只重试账号校验，不会自动补发投币、点赞、评论或私信等互动操作。

## 安装与使用

从本 Release 下载 `BiliDesk-Android-0.1.7-preview.apk`，直接覆盖安装0.1.6；不要先卸载或清除应用数据。该预览包使用相同签名，升级保留原有登录、设置和缓存。Actions 中的临时签名构建包仍只用于开发检查。

安装后在“我的”页面等待自动同步。无网络时可看到已保存的账号；网络恢复后自动重试。如果看到“平台已确认登录过期”，请使用官方扫码或网页登录。已经在旧版退出、卸载或被平台撤销的会话，不能凭空恢复。

视频、音乐、手势、弹幕和缓存的原有操作仍可参考 [0.1.6 使用说明](USAGE.pdf)；本页补充0.1.7登录恢复的变化。

## 验证

验证范围、旧版复现记录、单元测试与设备回归见 [0.1.7 验证说明](VALIDATION-0.1.7.md)。账号与网络返回使用明确的本地模拟数据，没有真实账号写入或扣币，不将模拟网络结果写成真实B站平台验收。

最终APK通过95项JVM测试，Lint 0错误；手机9项、横屏平板8项相关独立场景通过，包含真实系统Wi-Fi事件、进程结束后恢复，以及音乐/系统媒体控制和手机短视频互动入口回归。未新增K60或小米平板6物理设备验收。
