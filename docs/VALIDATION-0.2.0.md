## 本轮验证

`VisualRefreshDeviceTest`使用本地拦截响应、假账号和独立绘制的演示封面，实际操作推荐／热门、搜索、头像／个人页、主题切换、小播放条暂停／继续和音乐入口。核对状态栏与导航栏图标跟随暗色主题、音乐连续解码，并查看手机／平板的亮暗界面和横屏截图。

继续检查视频密度与指定列数的实际重排／持久化、分页错误停止自动重试、音乐导航恢复、歌词跳转与后台媒体会话、三种播放器样式及底部按钮对齐。普通视频的沉浸手势与平板播放设置按对应设备方法回归。

所有最终场景按独立instrumentation进程运行，记录实际主APK与测试APK摘要，不把旧版本、失败或重复运行算作新通过。

## 初期问题与边界

第一版小播放条在进度回调中读取变化中的时长，停止／切换媒体后可能以零时长计算，触发Material进度语义的NaN异常。现改为在每次组合中计算带零时长保护的有限进度，回调读取该固定值；初期崩溃日志保留，不计为成功。

小字原先继承较大的固定行距，造成时长标签与快捷入口偏高；已改为随字号排版。主题切换的窗口焦点回调负责重新应用系统图标颜色，完整播放器独立恢复沉浸效果。

手机与平板并行检查时，一次用于暂停的模拟点按实际按住了1050ms，日志记录为长按，暂停断言失败。关闭另一模拟器后，同一主APK在独立进程完成短视频全流程；初次失败保留并排除于通过数，不据此承诺所有物理设备的触摸时序。

参考APK的ARM64库可以读取并解析ELF信息；当前x86_64模拟器没有ARM原生桥，未运行其完整应用。本次视觉参考以主题／尺寸资源为依据，没有把原包资源或原生库加入应用。

测试使用隔离API35模拟器、独立音视频样片和假账号，无真实平台互动或扣币，未新增真实B站接口／CDN联调，也没有红米K60／小米平板6真机验收。未使用额度重置券。
