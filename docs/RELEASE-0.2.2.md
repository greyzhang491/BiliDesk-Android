# 0.2.2：播放网络、UP 主主页与我的关注

本版优化起播与拖动，并将作者入口、投稿搜索和关注列表连起来。预览版仍需在不同运营商与设备上持续验证。

## 播放与弱网

- 起播不再先等待视频和音频的两轮线路测速。默认使用平台提供的地址，读取失败后按已读位置切换平台提供的备用地址，音频和视频分别处理。
- 系统域名解析或响应读取长时间不返回时，元数据请求也受约9秒的独立总超时保护；快速连接失败最多额外重试一次，不重放账号写入。
- 部分HEVC视频配置被旧解析器拒绝时，自动回退H.264；普通网络超时不会被误判成编码问题。
- 有 SegmentBase/SIDX 元数据的视频使用 DASH 分段索引，拖动时读取目标片段。缺少索引的旧格式继续使用兼容播放。
- “自动”画质根据带宽选择可用码率，最高普通1080P；需要高帧率、高码率或4K时可手动选择，仍受账号权限和平台实际返回内容限制。
- 升级时，原1080P设置一次性调整为自动；之后手动选择会保留。设置中的线路选项改为“自动切换备用”与“仅首选线路”。
- 已进入播放错误状态时，网络恢复会尝试更新播放地址并保留进度；主动暂停的视频保持暂停。没有收到系统联网事件时，可以点重试。
- 首页与分区保留最近列表的文字、封面地址等元数据。首次使用且完全断网时仍需要联网获取内容；已有列表在请求失败时保留，不再只显示原始 `timeout`。

元数据快照位于本机私有缓存，按账号区分，最多8份、合计约1MB，每份最多32个视频，超过7天不再使用。它不保存Cookie、API响应正文或视频文件。独立音轨音乐仍只读取音频；播放优化没有开启自动下载，也没有改变手动缓存的保留规则。

## 作者与投稿

1. 视频简介显示实际作者头像，粉丝数在后台单独读取；资料读取失败可重试，不影响视频播放。
2. 短视频竖屏右侧加入UP头像，也可以点底部作者名进入主页。横屏继续使用常规播放控件，不叠加竖屏动作列。
3. 主页中输入关键词并提交“搜索这位UP主的投稿”，搜索范围限定为当前作者。普通视频、短视频、评论提及、音乐作者和原投稿入口共用该主页。
4. 从正在播放的视频进入主页，会看到“回到当前视频”与“定位当前视频”。定位会按发布时间缩小范围并核对视频ID，找到后在投稿网格中标注当前视频，方便查看相邻投稿。
5. 定位最多请求10页、约20秒；平台未公开的视频、缺少日期或数量、同日投稿较多等情况可能无法定位，可改用标题搜索。不会默默遍历全部投稿。
6. 主页打开时底层播放继续。短视频不会因为在主页浏览而自动切到下一条；从搜索结果选择投稿后，继续留在短视频模式，后续分页也限定为该UP及当前关键词；从结果中选择其他行时准确从该视频开始。音乐页面进入主页选曲继续使用音乐模式，其他板块不会因为后台有音乐而误切到音乐页。

## 我的关注

在“我的”点击“我的关注”，查看头像、昵称和简介，向下滚动自动分页，也可下拉刷新。点击头像或昵称可进入该UP的主页并搜索投稿；关注、取消关注成功后会同步相关按钮，并刷新关注列表。网络失败会保留已加载内容，提供重试。未登录时先进入登录流程。

关注列表来自平台接口，可能受到账号验证、隐私设置、风控或接口变动影响；读取失败会显示错误，不当作“没有关注”。
