# 0.1.9 手机竖屏音乐沉浸模式

[音乐、歌单与DIY说明](RELEASE-0.1.8.md) · [验证记录](VALIDATION-0.1.9.md) · [基础使用手册](USAGE.pdf)

手机竖屏点击底部「音乐」后，直接打开完整音乐播放器，隐藏「发现／短视频／分区／音乐／我的」导航及系统状态栏，让封面、歌词与播放控制使用完整空间，三种音乐样式均适用。窄于600dp的竖屏窗口采用这个布局，平板原有导航和横屏双栏继续保留。

- 点左上角返回箭头，或使用系统返回键／返回手势，回到进入音乐前的「发现」「分区」或「我的」，主导航恢复显示。
- 返回其他板块后音乐继续播放，可通过底部小播放条暂停、切歌或重新打开播放器。
- 播放器右上角仍可打开搜索、我的歌单和外观设置。搜索／歌单页保留小播放条，返回后恢复沉浸播放器。
- 手机旋转至横屏时使用适合横屏的导航布局，转回竖屏后再次隐藏主导航。切换复用同一播放器与曲目。
- 系统栏可以通过屏幕边缘滑动临时唤出；音乐页的返回箭头始终提供退出入口。

这次更新保留0.1.8的多歌单、合集／分P批选、独立音轨省流、歌词和三种样式。安装包沿用原预览版证书，可覆盖更新；源码与构建检查见[验证说明](VALIDATION-0.1.9.md)。
